## Current conclusion

The original broad three-knob or generic paused-KV claim is not defensible. The
N1 candidate tests whether the **local tool resource envelope**, resume
uncertainty, physical shared-memory/bandwidth risk, and thermal state jointly
change the best KV/admission action and improve board energy per successful
task beyond matched paused-KV, transition-aware, opportunity-cost, agent-power,
and edge-energy baselines.

Absence from this finite audit is not proof of novelty. Refresh primary sources
before any submission and follow the N1→N5 fallback ladder when overlap or
experiments falsify a higher claim.
